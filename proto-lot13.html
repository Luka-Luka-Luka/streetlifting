Écran 7 — Comparaison des passages

À rapporter : ce tableau une fois les DEUX fichiers passés sur la MÊME vidéo — proto-lot13.html puis proto-video.html, k = 1 dans les deux cas. La question n'est plus « jusqu'où peut-on dégrader l'image » (elle est tranchée : k = 1) mais « le gain du lot 14 se voit-il sur téléphone ». La colonne qui répond est mesures ms/img : c'est la seule qui chronomètre le code de mesure seul. « lecture ms/img » chronomètre getImageData, qui est identique dans les deux fichiers — si cette colonne diffère beaucoup, le téléphone a bougé (chauffe, autre application), et la comparaison ne vaut rien. La colonne k reste affichée comme contrôle : elle doit valoir 1 sur les deux lignes.
